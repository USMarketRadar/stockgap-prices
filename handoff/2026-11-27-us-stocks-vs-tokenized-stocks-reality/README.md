# USStockLive 자동 기사 발행 인계

사용자가 검토·수정한 최신 한국어 1~9절 원고 및 테더 포함 최종 그래픽 3개 인계. 이 자료는 사용자가 다른 대화에서 직접 발행하기 위한 것이며 이번 인계에서는 CMS 작성·발행·자동화 실행 금지. 기존 동일 주제 대기열 원고와 동일 slug CMS draft 가능성이 있으니 두 기사를 중복 등록하지 말고 사용자 선택 원고를 확인. 기존 CMS 기사 덮어쓰기는 별도 사용자 지시 필요. 원고의 여야 잠정합의 문구는 사용자의 수정 그대로 보존했으며 발행 전 최종 의결·공포 여부 확인. 주주총회 접근성 표현 및 상품별 약관과 출처 최신 검증 필요. 이미지 SVG는 이전 화면의 그래픽을 실제 파일로 재구성한 자료로, 발행시 CMS 이미지 또는 동일 데이터를 사용한 네이티브 표/차트 블록으로 삽입하고 각 언어에 맞게 현지화. 본문에 포함된 가상 사례 및 과세 비교는 실제 데이터/확정세액으로 표현하지 않는다.
